# Supplier Collaboration Hub

Prototipe web app Kelompok 42, PRI ITB 2026, untuk Paragon Corp. Isi dan data mengacu ke mockup deck Tugas Pekan 9.

## Cara membuka

Buka `dist/index.html` di browser, tanpa instalasi. Tampilan ponsel pemasok layar penuh: tambahkan `#/p/sari` di ujung alamat (juga `mandiri`, `aneka`, `kimia`).

## Membangun ulang

```bash
npm install
npm run build
```

## Batas prototipe

Semua nama pemasok, angka, dan biaya adalah data ilustrasi. Data tersimpan di browser, jadi sinkron hanya antar-tab pada perangkat yang sama. SAP, ERP, dan WhatsApp disimulasikan.
